# 🚀 QUICK START GUIDE
# ការណែនាំប្រើប្រាស់រហ័ស

## ជំហានទី 1: ដំឡើង Extension (Install Extension)

### Chrome:
1. បើក Chrome browser
2. ទៅកាន់: `chrome://extensions/`
3. បើក "Developer mode" (ខាងលើស្តាំ)
4. ចុច "Load unpacked"
5. ជ្រើសរើសថតនេះ: `New folder (29)`
6. រួចរាល់! ✅

### Microsoft Edge:
1. បើក Edge browser
2. ទៅកាន់: `edge://extensions/`
3. បើក "Developer mode" (ខាងលើស្តាំ)
4. ចុច "Load unpacked"
5. ជ្រើសរើសថតនេះ: `New folder (29)`
6. រួចរាល់! ✅

## ជំហានទី 2: ប្រើប្រាស់ (Use Extension)

### របៀបប្រើប្រាស់សាមញ្ញ:

1. **ចុច Extension Icon** (នៅលើ toolbar)

2. **ជ្រើសរើស Mode:**
   - **Single Prompt**: Generate មួយក្នុងមួយពេល
   - **Multiple Prompts (Queue)**: Generate ច្រើនតាមលំដាប់ ✨
   
3. **បញ្ចូល URL របស់ Google Flow Project:**
   ```
   https://labs.google/fx/tools/flow/project
   ```
   (ឬ URL ដែលមាន ID ផ្សេងទៀត)

4. **បញ្ចូល Prompt:**
   
   **Single Mode:**
   ```
   A beautiful sunset over mountains
   ```
   
   **Queue Mode (មួយបន្ទាត់មួយ):**
   ```
   A beautiful sunset over mountains
   A cat playing piano
   A dog dancing
   ```

5. **ចុច "▶️ Start Auto Generate"**
   
6. **រង់ចាំ Extension ធ្វើការ:**
   - Extension នឹងបើក/ទៅកាន់ Google Flow
   - វានឹងបញ្ចូល prompt(s) ដោយស្វ័យប្រវត្តិ
   - វានឹងចុច generate button ឬ press Enter
   - **Queue mode**: វានឹង generate ម្តងមួយៗតាមលំដាប់
   - វានឹងជូនដំណឹងពេលរួចរាល់

### Buttons ផ្សេងៗ:

- **🔗 Test Link:** ពិនិត្យមើលថា URL មានដំណើរការឬអត់
- **📄 Test Page:** បើកទំព័រក្នុង tab ថ្មី

### Settings:

✅ **Auto retry on error:** ព្យាយាមម្តងទៀតប្រសិនបើមានកំហុស (រហូតដល់ 3 ដង)
✅ **Notify when complete:** ជូនដំណឹងពេលបង្កើតរួចរាល់
⏱️ **Delay between prompts:** (Queue mode) ពេលរង់ចាំរវាងការ generate (5-300 វិនាទី)

## ជំហានទី 3: ពិនិត្យមើលលទ្ធផល

- រង់ចាំ Extension ធ្វើការ
- អ្នកនឹងឃើញ status updates
- ពេលរួចរាល់ អ្នកនឹងទទួលបាន notification
- វីដេអូនឹងមាននៅលើទំព័រ Google Flow

## 🔧 Troubleshooting (ដោះស្រាយបញ្ហា)

### បញ្ហា: Extension មិនដំណើរការ

**ដំណោះស្រាយ:**
1. Reload ទំព័រ Google Flow
2. ពិនិត្យ URL ថាត្រឹមត្រូវ
3. Reload Extension:
   - ទៅ `chrome://extensions/`
   - ចុចលើ reload icon

### បញ្ហា: ការបង្កើតបរាជ័យ

**ដំណោះស្រាយ:**
1. បើក "Auto retry" ក្នុង settings
2. ប្រាកដថាអ្នកនៅលើទំព័រត្រឹមត្រូវ
3. រង់ចាំបន្តិច រួចព្យាយាមម្តងទៀត

## 📋 Quick Tips (ចំណុចសំខាន់ៗ)

✨ **Extension នឹងចងចាំ:**
- URL ចុ(s) ចុងក្រោយ
- Mode ដែលបានជ្រើសរើស (Single/Queue)
- Settings របស់អ្នក

🎯 **ការប្រើប្រាស់ល្អបំផុត:**
- ប្រើ "Test Page" មុនពេលបង្កើត
- ពិនិត្យ prompt(s) មុនពេលចុច Start
- **Single mode**: សម្រាប់ test និង generation តែមួយ
- **Queue mode**: សម្រាប់ generate videos ច្រើន
- អ្នកអាចបិទ popup បានបន្ទាប់ពីចុច Start

🔄 **ប្រើម្តងទៀត:**
- គ្រាន់តែប្តូរ prompt
- ចុច Start ម្តងទៀត
- មិនចាំបាច់បិទបើក extension ទេ

📊 **Queue Mode Tips:**
- ដាក់ prompts មួយបន្ទាត់មួយ
- កំណត់[README.md](README.md) សម្រាប់ព័ត៌មានលម្អិត
2. មើល [QUEUE_MODE_GUIDE.md](QUEUE_MODE_GUIDE.md) សម្រាប់ការណែនាំ Queue Mode
3. មើល [TEST_INSTRUCTIONS.md](TEST_INSTRUCTIONS.md) សម្រាប់ការធ្វើតេស្ត
4. ពិនិត្យ Console (F12) សម្រាប់ errors
5 កុំបិទ tab ក្នុងពេល processing
- មិនចាំបាច់បិទបើក extension ទេ
